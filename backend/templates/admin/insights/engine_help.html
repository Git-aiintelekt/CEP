How Report Engines works

One row per workspace: the analytics engine its Insights reports run on, PostgreSQL (the live views on the workspace's own database) or ClickHouse (reporting tables loaded from them), and its query limits. A workspace without a row runs on PostgreSQL with the default limits. Nothing here changes a workspace's data.

  1. Backfill ClickHouse loads every dataset of the workspace and marks it migrating; reports still run on PostgreSQL.
  2. Reconcile counts every dataset on both engines and shows them side by side.
  3. Activate ClickHouse moves the workspace's reports, dashboards, exports and deliveries over; the data is then as of the last quarter hour.
  4. Roll Back to PostgreSQL returns to the live views at once.

The buttons sit at the top of a workspace's row. The server's ClickHouse connection is its environment, not this page; an empty connection means every workspace stays on PostgreSQL. Full chapter: Report Datasets and Report Engines in the Platform Guide.
