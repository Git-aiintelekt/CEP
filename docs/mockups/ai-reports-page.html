AI Reports shows in the Insights menu only when AI can be used: an AI provider with a key is on (the platform's or the workspace's own), AI is switched on for the workspace, and the person may build reports. Otherwise the item is not there at all. The page holds the prompt box with an optional Report Name, the run details of the prompts below it, and the prompt history, newest first, scrolled, which you can hide or clear. A report a prompt became is renamed with the pencil. The reports themselves are ordinary reports: they stay in Reports (marked AI) and can be put on any dashboard under Dashboards. The options differ in where the history sits.

What gets built, in words

  • AI Reports in the menu, above Reports, shown only when Ask for a Report is available to the person (a provider with a key switched on, AI on for the workspace, the report.edit right); hidden otherwise. Its page holds the box, Run Details and Prompt History. Reports loses the AI box and keeps the list.
  • Report Name: an optional field at the top of the box; the draft takes it, and the name field on the draft (already there) still edits it before Open in Editor.
  • Run Details: the steps of the prompt under way (as today), then the earlier runs of this visit with their time, tokens and outcome, scrolling inside the panel.
  • Prompt History: the person's prompts of the last 90 days, newest first, 30 at a time as you scroll; Show on or off is remembered per browser; Clear History hides them from the list (patch 0078 adds ai_prompt.cleared_at), never deletes them, so the month's count is unchanged; Use Again puts a prompt back in the box; the pencil renames the report a prompt became.
  • Reports and Dashboards: AI-made reports keep living in Reports, with an AI mark, and are added to dashboards like any report.
  • Help and tests: the Insights help's AI steps move to the new page; tests for the menu rule, history paging, hide, clear (count kept), rename, and the name field.
Recommendation: Option A. The page reads top to bottom in the order you work (name, prompt, watch it run, look back), the box stays wide enough for a long spec, and it works the same on a narrow screen. Option B suits wide screens where you reuse old prompts often, but squeezes the box.
