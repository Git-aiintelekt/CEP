Mockup, not the product. Static HTML on the app's colour and shape values. Insights → Reports, the Ask for a Report box as built (one box, paperclip, drop target), with the data to ask about, documents as attachments, and longer prompts. Sample names.

Three additions to the box: the data to ask about (all of it, the platform's, one of your databases, or your uploaded files), so the model reads only those fields; documents (PDF, Word, text, Markdown) beside images, for a report spec; and prompts up to 100,000 characters, with the counter shown only near the end. Documents and images go to the model with the prompt and are never stored. The options differ in where the data choice sits.

What gets built, in words

  • The data to ask about: All My Data (as today), the platform's datasets, each Report Database (its mapped datasets), or the uploaded files. The model is sent only the chosen fields, so answers are sharper and prompts cheaper. The last choice is remembered per browser.
  • Tables not mapped yet (a switch under a Report Database, on by default for administrators and report builders): the table names are read live (the same one statement as Map a Dataset), and the columns of the tables the prompt names or the model asks for, at most 20 tables. Nothing is stored. A draft on them is mapped as a dataset only when someone opens it.
  • Documents: up to 3, PDF, Word (.docx), text and Markdown, up to 10 MB and 100 pages each, by the paperclip, a drop or a paste. Claude reads PDFs as they are; OpenAI takes them as files; a Word file is read as text by C360 (no new package). Like images, they go to the model with the prompt and are never stored; the draft says what it read.
  • Prompts up to 100,000 characters (about 25,000 words), checked on the server too; the counter appears from 90,000. Truly unlimited is not possible: a model reads about 200,000 tokens a request, and every character is paid for. A longer spec goes in as a document.
  • Usage: a prompt with documents still counts as one prompt; the AI provider bills the tokens, so the month line on the box stays the guide.
  • Help: Ask for a Report and "Add images to a prompt" become "Add a spec or images to a prompt"; tests for the data choice, documents, the limits, and a draft on an unmapped table.
Recommendation: Option A. You described the order as choose the database, then run the prompt; "Ask about" at the top of the box makes that the first thing seen, and with documents and a long prompt the choice is too important to sit as a quiet pill next to the model. Option B is tidier for people who mostly keep All My Data.
