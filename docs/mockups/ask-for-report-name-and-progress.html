What gets built, in words

  • Progress: the box sends a progress id with the prompt; the server writes each step to the cache as it starts and ends (the documents, the database's tables, each Claude call, the check, the preview) and GET /insights/assistant/progress/<id>/ returns them; the box asks every second while it waits. Only the steps that apply are shown. Nothing is stored after ten minutes.
  • The name: in option A an optional Report Name in the box goes with the prompt and wins over the model's; in option B the draft's name is a field and Open in Editor sends it. Either way it is checked like any report name (200 characters) and kept with the draft.
  • Unchanged: one prompt is still one request to the server (no new background job), the 100-second limit stays, and a failure says which step it stopped at.
  • Help and tests: the Ask for a Report steps in the help; tests for the steps reported, the name kept, and the progress shown and folded.
Recommendation: Option A for the progress, Option B for the name. The listed steps show what was read and what is happening, which matters on a long spec with a database's tables; a name field on the draft lets you name the report once you see what it became, without one more field in the box. Each option works on its own too.
