Mockup only. Create Report as a pop-up in the same frame as Create Campaign and Create Journey (768px, step line, icon tiles, Back / Cancel / primary footer). It opens over the Reports list from New Report. Datasets and databases are sample data.

1 · Step 1 of 2 · How to Start

Four ways in, one place. Start from Data is picked by default. The other three take you straight to where that work happens: AI Reports, the Base Reports window, or the query window. They don't add a step here.

Create Report

Step 1 of 2 · How to Start

How do you want to start?

Most Common Start from Data Pick a dataset, one of your databases or an uploaded file, and choose what to show.
Ask AI Describe the report in your own words, and AI drafts it for you to check. Opens AI Reports
Use Base Reports Add a ready-made pack, such as Email Campaign Reports, as your own copies. Opens the Base Reports window
Write a Query Pick tables and columns, or write the SELECT, on one of your databases. Opens the query window

2 · Step 2 of 2 · Pick the Data

One searchable list instead of a long page. The groups on the left replace the capital-letter headings. Each dataset says what it holds in plain words. Connect a Database and Upload a File sit at the foot of their groups. Name fills itself in once you pick, and Create Report opens the editor as today.
