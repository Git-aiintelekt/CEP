Mockup only: four other ways to do step 2 (picking the data), each in the same Create Report frame. Sample data. What makes today's step 2 slow: you pick a group before you can see anything, read a description for every row, then fill in Name and Component before you can go on.

A · Start from What You Want to See Recommended

You pick a question in your own words, not a dataset. One click picks it, and the name fills itself in from that choice. Component is left on Automatic, since it can already be changed on the report page. Your own databases and files are chips underneath, for the few people who need them.

Quicker becauseIt's one click on a plain-language card, with nothing to type and no fields to fill in.
Watch forThe four cards are written for C360's four datasets. Any new dataset needs a card written for it.

B · One Step: Pick the Data, Done

This drops step 1 altogether. The pop-up opens straight on the data, and Ask AI, Base Reports and Write a Query become a line of links at the bottom. Two clicks from New Report to the editor: a tile, then Create Report.

Quicker becauseThere's no "How to Start" step, and the common path is the whole pop-up.
Watch forAsk AI and Base Reports become small links, so fewer people may find them.

C · Pick the Data, Then a Starting View

Pick the data on the left. Then pick a ready-made starting point for it, each with a small preview of its shape. The editor opens on something useful ("Sends by Campaign", "Delivered Rate by Channel") instead of the dataset's first columns.

Friendlier becausePeople see what they'll get before they get it, and don't land on an empty-looking editor.
Watch forThe starting views need defining per dataset. That's frontend work: a few definitions, like the starter used today.

D · Search First

A single search box that's already focused: "What do you want to report on?". Typing finds datasets, your databases, your files and the fields inside them, so "revenue" finds Attributed Orders. The arrow keys and Enter create the report without touching the mouse. Before typing, it lists the data you used most recently.

Quicker becauseRegular users who know what they want can type and press Enter.
Watch forNew users may not know what to type. It works best paired with A or B as the view before anything is typed.
