Edit on the dashboard itself, with a faint column grid. Tiles show a small toolbar on hover: drag, size, edit, duplicate, remove. A dashed + box marks where the next tile goes. The rows' layout menus and every arrow are gone; a tile's size replaces them.

Questions for you

Sizes instead of row layouts?

Grid with tile sizes becomes the main way; Free Canvas stays for exact placing. Or keep today's row layouts beside the sizes?

Dashboard templates

The panel needs the list of dashboards each Base Reports pack adds. If the pack list does not say, it is a small backend ask.

Headline numbers

Today a dashboard's number tiles are ordinary tiles you add. Keep it that way, or always show the first row as headline numbers?
