Mockup for review, not built. Sample data like NWA's. Every page gets the Reports list's shape: a header with its count and one Add button, a filter line (search, chips, Clear Filters, all kept in the address), the table in a card with Title Case headers, one working ⋯ per row, and pages of 25 or 50. Adding and changing open the shared create pop-up: Step 1 of 2 when there is more than one screen, a fixed header and buttons, and only the middle scrolls, so Save is always in view.

1 · Scheduled

New Schedule lives on the page: pick a report or a dashboard, then when, as what and to whom. Two steps: What to Send, then When and to Whom. A row's ⋯ → Edit Schedule opens the same pop-up on step 2, filled in. Recipients show as people, not a count. Alerts get their own tab in the same style, with New Alert in two steps too: Pick a Report, then the alert.

Questions for you

Steps where a pop-up is long

New Schedule, Upload a File, Add a Formula, Add a Benchmark and New Alert take two steps each; Rename, Replace File and the delete checks stay one screen. Edit opens on the step with the detail people change most.

“Act” becomes “Needs Action”

The benchmark band and Explain's verdict would both say Needs Action. Explain's verdict wording is shared with the report page, so it changes there too.

Send Now

A schedule's ⋯ could offer Send Now to test it. The API has no "send now" today, so it would be a small backend ask. Leave it out?
