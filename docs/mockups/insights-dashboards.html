Insights dashboards, mocked up (Phase C). A dashboard is a page of tiles, each tile a saved report shown in one of its views, or one of its numbers as a figure. One period at the top applies to every tile. The two options below differ in how tiles are laid out: a free grid you drag on, or rows of tiles with set widths. Everything after the options is shared: the period, Add Tile, the tile menu, favourites and folders on the Reports list, version history, and the run log. Data: Northwind Apparel, September and October 2026.

What is the same in both options

  • A dashboard belongs to the workspace like a report: private or shared, an owner, report.edit to make one, favourites, a version each time the layout is saved.
  • A tile is a saved report in one of its views, or one figure from it. The tile runs the report through the same engine with the dashboard's period added as a filter on the dataset's time field; results are cached for a minute like every run, so a dashboard of seven tiles is seven short queries, each under the engine's limits.
  • Compare With Previous Period runs the figure twice. Figures show the change; charts and tables do not.
  • Viewing is read-only; Edit turns the layout controls on; Done saves. Nothing moves by accident.
  • Folders, favourites, version history and the run log are the same under either option.

How the options differ

Option 1 · Free GridOption 2 · Rows of Tiles
Placing a tileDrag anywhere on 12 columns; resize by the corner; others shuffleInto a row; move with arrows; width from a short list (1 to 4 across, wide and narrow)
TidinessUp to the person; gaps and ragged edges are possibleAlways aligned, like Home's bands
PhoneCollapses to one column in layout orderEach row stacks; the order is the rows' order
Libraryreact-grid-layout, about 30 KB gzip in the Insights chunkNone; CSS grid
Saved layoutx, y, w, h per tilerows, each with a width preset and tiles in order
Growing laterAlready free-formA free grid can be added as a second layout mode without changing what is saved

Recommendation: Option 2 for the Beta. It keeps every dashboard looking like the rest of C360 with no new dependency, and its saved shape converts to a free grid later if people ask for one.
