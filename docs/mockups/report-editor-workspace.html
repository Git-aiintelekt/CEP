Questions for you

Hide the side menus while editing?

The workspace uses the full width. The navy bar stays, so search and your account are still there.

Update Automatically

A new switch. On by default, as today. Off would mean you click Run Preview after each change.

Drop Field Wells and Steps?

The single builder replaces both. Everything they set is still here. Is anyone attached to Field Wells for pivots, so it should stay as an option?
