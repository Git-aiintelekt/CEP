Questions for you

Keep both builders?

Field Wells and Steps build the same report two ways. Keeping both costs a switch on every visit. Should one be the default for new people (Steps reads more easily)?

Leave without saving

Today Cancel leaves at once and drops the changes. Should it ask first when there are unsaved changes?

“Report Filters” name

The questions a viewer answers (Period, Campaign) are called Report Filters, and the Filters well (rows kept) sounds the same. Rename the first to “Viewer Filters”?
