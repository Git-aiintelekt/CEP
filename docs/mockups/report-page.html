Questions for you

Update straight away?

Should a filter change run the report at once (as here), or keep a Run Report button? Running at once is simpler; a big query may take a few seconds each time.

“Grid” or “Table”?

The mockup keeps today's word, Grid. Table may be clearer to most people; the list pages already call it a table.

Change vs previous period Backend

Figures can't show “+12% vs previous period” yet: a report run returns no previous value unless the report adds a comparison column. Dashboards' figure tiles already get one. We'd ask the backend team for the same on a report run.

Which figures?

The mockup shows each measure's total plus two worked out (Average Order, Credited Share). Should a report owner pick its figures, or do we always show the totals?

Highlights with no AI

Highlights are written by simple rules: biggest change, top and bottom value, largest share. Are rule-written lines enough when the AI add-on is off?

Not credited

Orders with no campaign show “—” as the campaign name. The mockup writes “Not Credited”. Is that the wording you want?
